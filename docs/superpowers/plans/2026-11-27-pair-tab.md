# Pair Tab and Back to Top Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the plus into a centre "Pair" tab, and give long walls and every tab a way back to the top.

**Architecture:** Client only. `Tab` gains `"pair"`, and `TabBar` draws five tabs with the centre one as an accent disc. The wall's header plus from v0.7.0 is removed. The A–Z rail gains an "↑" mark above A, which scrolls to the top. Tapping the tab whose own page you're on scrolls to the top instead of reloading.

**Tech Stack:** React 19, TypeScript, plain CSS with tokens, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-27-pair-tab-design.md`

## Global Constraints

- No server change: nothing under `src/worker/`, `src/shared/` or `drizzle/` changes.
- Colours come from `src/client/styles/tokens.css` only. Light and dark settings, 44px targets, text 4.5:1 or better, and icons 3:1.
- It renders at 320, 375, 414 and 768px with no sideways scroll (`scripts/shoot.mjs`). Tab labels never wrap or clip.
- Tests go by role and visible text. No snapshot tests.
- Tab order is Books, Holding, Pair, Friends, More. The Pair tab's label reads "Pair", and its href is `/pair`.
- The empty wall keeps its "Pair a book" link. More drops its "Pair a book" entry.
- One branch, `pair-tab`, from an up-to-date `main`, and one pull request. The maintainer approves the merge and the tag.
- After each task: the ordinary task review **and** an antagonist pass (`.claude/agents/antagonist.md`).
- No private data (`storygraph_export.csv`) in fixtures, screenshots or the PR.

## Review Focus

1. **"Holding" at 320px with five tabs.** Each tab is 64px wide, so the label must stay on one line, unclipped, in both settings. This is checked by shots in Task 1.
2. **The rail's letters still land under the finger.** Adding a 28th band shifts every band, so a press at a letter's band must pick that letter. This is tested in Task 2.
3. **Dragging from "↑" down into the letters, and back up.** The page must go to the top once, then pick letters, then go to the top again, with no repeated scrolls while the finger rests on "↑". This is tested in Task 2.
4. **Tapping the active tab on a page that isn't its root.** For example, Books is active on `/collections/…`; the tap must still navigate. This is tested in Task 3.
5. **Modified clicks on a tab** (cmd/ctrl-click, middle click). They must still open normally and must not scroll. This is tested in Task 3.

### Task 3: The tab you're on scrolls to the top

**Files:**
- Modify: `src/client/TabBar.tsx`
- Test: `src/client/TabBar.test.tsx`

**Interfaces:**
- Consumes: `tabRoot` and `TabBar({ active })` from Task 1.

- [ ] **Step 1: Write the failing tests** (stub `location.pathname` and `window.scrollTo` the way other client tests stub `location`):
  - "tapping Books on / scrolls to the top and doesn't navigate". `active="books"` and pathname `/`. A plain click on Books calls `scrollTo` with top 0, and the click event's `defaultPrevented` is true.
  - "tapping the active tab away from its own page navigates". `active="books"` and pathname `/collections/k1`. The click isn't prevented, and `scrollTo` isn't called.
  - "a modified or middle click opens normally". Clicks with `metaKey`, `ctrlKey`, `shiftKey`, `altKey`, and `button: 1` (as an `auxclick` or `click`) aren't prevented.
  - "tapping a tab that isn't active navigates". `active="books"` with a click on Holding isn't prevented.
- [ ] **Step 2: Run them and see them fail.**
- [ ] **Step 3: Implement.** In `TabBar`, add an `onClick` that runs only when `tab === active`, `location.pathname === tabRoot[tab].href`, the button is 0, and no modifier key is held. It calls `preventDefault()` and then `window.scrollTo({ top: 0, behavior: "smooth" })` **(call: smooth, as phone apps do; use "instant" under `prefers-reduced-motion: reduce`)**.
- [ ] **Step 4: Run** `pnpm test`. Expected: all pass, with lint and typecheck clean.
- [ ] **Step 5: Commit** `feat: tapping the tab you're on scrolls back to the top`.
